# Car-Price-Prediction-using-Ridge-Lasso-and-ElasticNet-Regressions

## Overview

This project aims to predict the price of cars based on its various specifications as given in the dataset. Besides this project is done to practically apply Regularization techniques on model building and learn how they play a key role to prevent overfitting.

## Dataset

The Car Price Assignment, sourced from Kaggle, includes various specifications such as Name of the Car, Fuel type, Engine Location, Drive wheel, Car's length, width, height etc. to predict the Car's Price.

## Requirements

- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn

## Prediction Process

1. Start with downloading the CarPrice_Assignment dataset from the repository
2. Install the required libraries in Jupyter Notebook
3. Check for any inconsistencies, missing or null values and outliers in the data and fix them
4. Explore the data, uncover patterns and identify potential issues
5. Train the model using Ridge, Lasso, ElasticNet Regressions and evaluate it using various performance metrics
